# TermCode Language Libraries

Official Toolchain & Library Repository for TermCode IDE (Android aarch64).

## 🚀 1-Line Installation via Terminal
Run the command below in the TermCode / Termux terminal for your desired language:

### Python (Python 3.14 + HTML/CSS Server)
```bash
curl -sL https://raw.githubusercontent.com/raj40870-pixel/library/main/install.sh | sh -s python
```

### C & C++ (Clang, Clang++, libc++, Make)
```bash
curl -sL https://raw.githubusercontent.com/raj40870-pixel/library/main/install.sh | sh -s c_cpp
```
